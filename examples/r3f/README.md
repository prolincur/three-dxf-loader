# three-dxf-loader — React Three Fiber example

Minimal demo showing `DXFLoader` used the React Three Fiber way: since it implements
the standard `THREE.Loader` interface, it plugs directly into `useLoader`, same as
`useLoader(GLTFLoader, url)`.

See `src/dxf-example.js` for the integration, `src/index.js` for the scene setup.

## Run

```
pnpm install
pnpm start
```
